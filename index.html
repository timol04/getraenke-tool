Datenschutzerklärung

Wir nehmen den Schutz deiner persönlichen Daten ernst. Diese Datenschutzerklärung informiert dich darüber, welche Daten wir über unser Tool erheben.

1. Keine Speicherung persönlicher Bestelldaten

Wenn du über unser Tool Getränke zusammenstellst und das PDF erstellen lässt, kannst du Angaben machen (z. B. deinen Namen). Wichtig: Diese Daten verbleiben lokal auf deinem Gerät und werden niemals auf unsere Server übertragen oder dort gespeichert.

Wenn eine Bestellung in unserem System abgelegt wird, speichern wir ausschliesslich anonyme Bestelldaten (gewählte Artikel, Mengen). Namen, Adressen oder Telefonnummern werden nicht gespeichert.

2. Feedback-Formular

Wenn du uns Feedback sendest, speichern wir ausschliesslich die Textnachricht. Wir erfragen und speichern keine E-Mail-Adressen (ausser, du schreibst sie freiwillig in den Text).

3. Technische Daten

Unsere Website nutzt GitHub Pages und Supabase. Aus technischen Gründen werden hierbei IP-Adressen verarbeitet, um die Website auszuliefern.
